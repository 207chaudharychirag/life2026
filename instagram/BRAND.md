## Visual System

Consistency of *system* matters far more than beauty of any single post. The
grid should be recognisable at a glance while scrolling.

### Colour
```
Ink        #0B0D0F   backgrounds, primary text on light
Paper      #FAFAF8   light backgrounds
Signal     #FF5C35   accent — hooks, highlights, CTAs. USE SPARINGLY
Muted      #6B7280   secondary text
Rule       #E5E7EB   dividers, borders
```

Dark-dominant grid with a single hot accent. Reads as technical and confident,
and — importantly — does *not* look like the pastel-gradient AI-slop aesthetic
every competitor uses. Looking visually different from the niche is free
differentiation.

### Type
- **Headline:** heavy grotesque, tight tracking, 2–3 words per line max
- **Body:** same family, regular weight, generous line height
- One family, two weights. That is the whole system.

### Carousel anatomy (6–8 slides)
```
1  HOOK        oversized type, minimal, one idea, accent colour
2  CONTEXT     the setup — why this matters
3-6 PAYLOAD    one idea per slide, screenshots where real
7  HONESTY     the caveat, cost, or limitation
8  CTA         single action + handle
```

### Rules
- Real screenshots beat generated images every single time — use them wherever
  the content is a real build
- Generated imagery is for concepts and abstractions only
- Every slide legible as a thumbnail
- Same template every post; vary content, never layout
- Accent colour on at most one element per slide

## Voice

**Is:** direct, specific, numbers-first, willing to say "this didn't work"
**Is not:** hype, emoji-stacked, "game-changer", "🤯", fake urgency

Litmus test: *would you say this sentence out loud to a colleague?*
If not, rewrite it.

Write short. Cut every sentence that survives being cut.
